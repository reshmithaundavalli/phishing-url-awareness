# Phishing URL Awareness

## About the Project
A Python-based tool that checks URLs for
suspicious patterns and helps users identify
potential phishing websites.

## Features
- URL validation
- Detection of suspicious URL patterns
- Basic phishing awareness
- Safe and suspicious URL classification

## Technologies Used
- Python
- Regular Expressions

## How to Run

1. Install Python 3.13.5
2. Clone this repository.
3. Run the program:

bash
python phishing_checker.py


## Project Structure

- phishing_checker.py - Main Python program
- tests/test_samples.md - Test evidence
- screenshots/ - Program screenshots
